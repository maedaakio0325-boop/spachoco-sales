# SPACHOCO OS 引き継ぎメモ（2026-10-07 時点）

クラウドのセッション「スパチョコ経営者会議の議事録まとめ」から、Mac のセッションへ引き継ぐためのメモ。
このリポジトリは公開なので、名前・コード・パスワードなどはここに書かない。

## 何を作っているか
- **SPACHOCO OS**（https://maedaakio0325-boop.github.io/spachoco-sales/minutes.html）
  - 議事録・宿題・会議の準備と進行（タイマー・台本・事前の進捗確認）
  - AIに相談（壁打ち）とカルテ、マニュアルで学ぶ（確認テスト）
  - 店舗ごとの表示（左端の店舗アイコン）、立場ごとのメニュー、組織図
- データは Firebase プロジェクト `spachoco-os`（Firestore・東京）。Google ログイン。権限ルールは `firebase/firestore.rules`
- 「スパチョコの教え」79件（研修録音・夢ノート・原田塾・アチーブ教材・会長の言葉）と、確認テスト付きマニュアル5本は、本番の Firestore に取り込み済み
